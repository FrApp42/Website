# VCards

VCards est un parseur vCard léger, conforme au standard et tolérant, écrit en C#, qui permet de lire et de sérialiser des vCards.

Les versions suivantes sont prises en charge :
* Version 2.1
* Version 3.0
* Version 4.0

## Installation

```nuget
Install-Package FrApp42.Net.VCards
```

## Utilisation

L'utilisation détaillée est disponible dans la [documentation en ligne](https://frapp42.github.io/Net.VCards/).
