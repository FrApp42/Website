# Intro

Bienvenue dans la documentation de **Frenchy Apps 42**. Vous y trouverez comment installer et utiliser les projets open source publiés par l'organisation [FrApp42](https://github.com/FrApp42).

La plupart de nos bibliothèques sont écrites en C# et distribuées sous forme de [paquets NuGet](https://www.nuget.org/profiles/FrenchyApps42). Le code source, les tickets et les contributions se trouvent sur GitHub, dans le dépôt de chaque projet.

## Projets

### Bibliothèques

| Projet | Description | Documentation |
|---|---|---|
| ACR122U | Lire des cartes NFC avec un lecteur ACR122U | [ACR122U](/docs/acr122u/) |
| Tools | `FrApp42.System` et `FrApp42.Web` : utilitaires pour les opérations système et web | [Tools](/docs/tools/) |
| TPLink | Lire et envoyer des SMS avec un routeur TP-Link Archer MR600 | [TPLink](/docs/tplink/) |
| VCards | Parseur et sérialiseur vCard (2.1, 3.0 et 4.0) | [VCards](/docs/v-cards/) |
| WPF.Pwsh | Contrôle WPF hébergeant une vraie session PowerShell | [WPF.Pwsh](/docs/wpf-pwsh/) |
