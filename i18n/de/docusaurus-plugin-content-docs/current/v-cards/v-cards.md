# VCards

VCards ist ein standardkonformer, schlanker und fehlertoleranter vCard-Parser in C#, der das Lesen und Serialisieren von vCards unterstützt.

Folgende Versionen werden unterstützt:
* Version 2.1
* Version 3.0
* Version 4.0

## Installation

```nuget
Install-Package FrApp42.Net.VCards
```

## Verwendung

Die ausführliche Verwendung findest du in der [Online-Dokumentation](https://frapp42.github.io/Net.VCards/).
