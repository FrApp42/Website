# Tools

Here you will find the documentation of all NuGet packages developed in the [Tools](https://github.com/FrApp42/Tools) repository.

## Packages

| Package | Description | Documentation |
|---|---|---|
| `FrApp42.System` | Classes helping you to execute system operations | [System](/docs/tools/system/) |
| `FrApp42.Web` | Classes helping you to execute web operations | [Web](/docs/tools/web/) |

## Content

### System

* **Awake**: keep a machine awake, with the screen on or off
* **IsOnline**: ping a device by hostname or IP address to check if it is online
* **Shutdown**: shut down a Windows device remotely through SMB
* **WakeOnLan**: power on a device with its MAC address

### Web

* **Request**: simplify HTTP requests (JSON and XML, binary and raw files)

## Installation

```nuget
Install-Package FrApp42.System
Install-Package FrApp42.Web
```
