# Intro

Welcome to the **Frenchy Apps 42** documentation. Here you will find how to install and use the open source projects published by the [FrApp42](https://github.com/FrApp42) organization.

Most of our libraries are written in C# and distributed as [NuGet packages](https://www.nuget.org/profiles/FrenchyApps42). The source code, issues and contributions live on GitHub, in each project's repository.

## Projects

### Libraries

| Project | Description | Documentation |
|---|---|---|
| ACR122U | Read NFC cards with an ACR122U card reader | [ACR122U](/docs/acr122u/) |
| Axios.Net | An axios-like HTTP client for .NET | [Axios.Net](/docs/axios-net/) |
| Tools | `FrApp42.System` and `FrApp42.Web`: helpers for system and web operations | [Tools](/docs/tools/) |
| TPLink | Read and send SMS with a TP-Link Archer MR600 router | [TPLink](/docs/tplink/) |
| VCards | vCard parser and serializer (2.1, 3.0 and 4.0) | [VCards](/docs/v-cards/) |
| WPF.Pwsh | WPF control hosting a real PowerShell session | [WPF.Pwsh](/docs/wpf-pwsh/) |

### Applications

| Project | Description | Documentation |
|---|---|---|
| DeskPilot | Open source server and console for RustDesk | [DeskPilot](/docs/deskpilot/) |
| Factos | InvoiceShelf clone written in C# / Blazor | [Factos](/docs/factos/) |
